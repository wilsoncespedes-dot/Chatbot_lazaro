# Manual de ejemplo: Facturador Demo

Este manual es inventado y sirve solo para evaluar el chatbot. No contiene datos reales.

## Alta de usuarios

Para dar de alta un usuario nuevo, el administrador entra en Ajustes y pulsa el botón Crear usuario.
Cada usuario recibe una contraseña temporal que caduca a las 24 horas.
Un usuario bloqueado se desbloquea desde Ajustes, en la sección Seguridad.

## Horarios de soporte

El soporte técnico atiende de lunes a viernes de 9:00 a 18:00, hora de Madrid.
Los sábados el soporte atiende de 10:00 a 14:00 solo por correo electrónico.
Los domingos y festivos nacionales no hay soporte.

## Copias de seguridad

El sistema realiza una copia de seguridad automática cada noche a las 03:00.
Las copias se conservan durante 30 días.
Para restaurar una copia, el administrador debe abrir Ajustes y elegir Restaurar copia.

## Planes y límites

El plan Básico permite hasta 3 usuarios y 100 facturas al mes.
El plan Profesional permite hasta 15 usuarios y 1000 facturas al mes.
El tamaño máximo de cada archivo adjunto es de 10 MB.

## Facturas

Una factura emitida no se puede borrar; se corrige emitiendo una factura rectificativa.
Las facturas se pueden exportar en formato PDF y en formato CSV.
